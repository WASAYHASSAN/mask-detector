# Mask Detector App

A real-time face mask detection application that identifies whether a person is wearing a face mask or not. Built using YOLOv8 and Streamlit, this lightweight yet powerful tool is suitable for deployment in workplaces, hospitals, schools, and other high-risk environments.
---

## ✅ Features

- Detects **two classes**:
  - **With Mask**
  - **Without Mask**
- Accepts:
  - Uploaded images
  - Uploaded videos
  - Real-time webcam stream
- Fast, accurate, and lightweight
- Easy-to-use Streamlit interface
- Built for both desktop and web deployment

---

## Model Details

- **Architecture**: YOLOv8 (Ultralytics)
- **Framework**: PyTorch
- **Input Size**: 640x640 (adjustable)
- **Classes**:
  - `0`: With Mask
  - `1`: Without Mask
- **Model File**: `mask_detector.pt`
